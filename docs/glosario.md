# glosario.md — Study Organization

Cada término del negocio en una o dos líneas, sin ambigüedades.

---

| Término | Definición |
|---|---|
| **Materia** | Asignatura o curso que el estudiante está cursando. Tiene nombre y color identificador. |
| **Evaluación** | Evento académico con fecha fija: puede ser un examen, parcial, trabajo práctico o entrega. La carga y actualiza el estudiante. |
| **Tipo de evaluación** | Categoría del evento académico: Examen, Parcial, Trabajo Práctico o Entrega. |
| **Estado de evaluación** | Etapa actual de una evaluación: Pendiente → En preparación → Listo → Rendido/Entregado. |
| **Tarea** | Acción concreta que el estudiante necesita completar, con prioridad y fecha límite. No es un evento académico formal. |
| **Prioridad** | Nivel de urgencia de una tarea: Alta, Media o Baja. |
| **Dashboard** | Vista principal de la aplicación. Muestra un resumen de lo más urgente: próximas evaluaciones, tareas de la semana y recordatorios. |
| **Recordatorio** | Alerta visual dentro del dashboard para evaluaciones o tareas cuya fecha cae en los próximos 14 días y no están finalizadas. |
| **Historial** | Sección donde aparecen las evaluaciones y tareas cuya fecha ya pasó, independientemente de su estado. |
| **Nota de materia** | Texto libre (apunte u observación) vinculado a una materia específica. |
| **Color identificador** | Color elegido por el estudiante al crear una materia, usado para distinguirla visualmente en toda la app. |
| **MVP** | Versión mínima del producto que cubre las funcionalidades esenciales sin características adicionales. |
| **ABM** | Alta, Baja y Modificación: operaciones básicas de gestión de datos. El proyecto va más allá de un ABM simple. |
| **Datos de ejemplo** | Información ficticia cargada automáticamente al levantar la app por primera vez, para que el usuario vea la interfaz con contenido real. |
